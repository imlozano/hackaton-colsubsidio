# Hero Illustration Style

## Style
- Cute 3D illustration
- Soft rounded shapes
- Plastic matte material
- Warm lighting
- Soft ambient shadows
- Friendly character design
- High quality render
- Clean edges
- Transparent background
- Premium startup landing page look

## Do NOT use

- realistic textures
- glossy reflections
- hard shadows
- noisy backgrounds
- outlines
